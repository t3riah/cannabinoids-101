# Cannabinoids 101: An Immersive Atmospheric Masterclass Reader

Interactive single-page masterclass reader covering the human Endocannabinoid
System (ECS), phytocannabinoids, pharmacokinetics and consumption routes,
terpenes and entourage synergy, and CYP450 drug-interaction safety.

Live site: https://t3riah.github.io/cannabinoids-101/

## Contents

- `index.html` — the complete reader (single self-contained file, 81,239 bytes).
  Only external dependency is the Tailwind CSS CDN plus Google Fonts.
- `.nojekyll` — disables Jekyll processing on GitHub Pages.

## Features

- 4 mastery levels: ECS fundamentals, pharmacokinetics/routes, terpenes,
  CYP450 safety
- Interactive ECS body hotspot map, phytocannabinoid matrix, decarboxylation
  temperature gauge, plasma-concentration route simulator, terpene selector,
  CYP450 drug checker
- Searchable glossary, rich-concept modals, 2-question checkpoint quiz
- Atmosphere settings: visual themes, text scale, ambient synth tone,
  synapse canvas toggle

## Notes

- Educational content only. The drug-interaction checker is a general
  educational reference, not medical advice.
- Known minor gap (as published): the Details buttons on the THCV and CBC
  matrix cards open no modal, as those two compounds have no glossary entry
  in the file yet.
